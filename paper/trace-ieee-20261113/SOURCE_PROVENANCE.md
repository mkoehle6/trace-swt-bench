# Sources and template provenance

Accessed November 13, 2026:

- Project guidelines: https://github.com/DePaul-SE-Team/SE443-333-final-project-guideline (Sections 6, 8, 11, and 12 reviewed).
- Exact IEEE template linked by the guidelines: https://www.overleaf.com/latex/templates/ieee-conference-template/grfzhhncsfqn (official IEEE conference starter, `IEEEtran` conference option).
- IEEEtran package information and license: https://ctan.org/pkg/ieeetran (version 1.8b, LPPL 1.3).
- Unmodified bundled class: https://mirrors.ctan.org/macros/latex/contrib/IEEEtran/IEEEtran.cls . Original class comments retain authorship and licensing information.
- SWT-Bench paper: https://arxiv.org/abs/2406.12952 . Bibliographic authors/title checked against the source.
- Harness repository: https://github.com/logic-star-ai/SWT-Bench . The experiment uses the locally recorded immutable commit, not a claim about today's default branch.
- mini-SWE-agent: https://github.com/SWE-agent/mini-swe-agent . The recorded installed experiment version is 2.4.6.

Experimental results are derived from the existing local TRACE generation/evaluation artifacts, not from web summaries or guideline examples. `evidence.json` lists paths and hashes. The draft uses the official template's document class, author-block structure, abstract, keywords, numbered sections, two-column layout, and numbered references; it omits sample template text.

The PDF was compiled in a disposable container using the existing Matplotlib benchmark image solely as a source of installed LaTeX tools, with network disabled and only the paper directory mounted. This did not alter any image, source checkout, generation configuration, or prediction.
